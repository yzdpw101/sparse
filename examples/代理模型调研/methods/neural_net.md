# 神经网络代理模型

## 原理

用神经网络 (NN) 拟合输入 (位置/幅度) → 输出 (PSLL/方向图) 的映射：

```
输入: x ∈ R^n (n = 2×Ne 对称半阵元位置+幅度)
输出: y ∈ R^m (m = N_θ 归一化方向图, 或标量 PSLL)
网络: 多层全连接 (MLP) 或 U-Net (方向图)
```

### 常用架构

| 架构 | 输入 | 输出 | 参数量 | 适用场景 |
|------|------|------|--------|----------|
| **MLP** | 位置+幅度 | PSLL (标量) | ~10K | 快速 PSLL 预测 |
| **MLP** | 位置+幅度 | 方向图 (N_θ) | ~100K | 全方向图预测 |
| **U-Net** | 位置序列 | 方向图 | ~500K | 序列输入 |
| **ResNet** | 位置+幅度 | 方向图 | ~200K | 深层网络 |

### 训练策略

1. **直接训练**: 大量 HFSS 采样 → 训练 NN → 在 NN 上优化
2. **迁移学习**: 粗模型 AF 数据预训练 → 少量 HFSS 微调
3. **数据增强**: 利用对称性 (左右镜像) 增加训练样本

## 在天线阵列优化中的应用

### 工作流

```
1. 数据采集
   - LHS 生成 1000-5000 个位置配置
   - 每个配置用 AF 计算方向图 (或 HFSS)
   - 构建数据集: {(x_i, pattern_i)}

2. 训练
   - 80/20 划分训练/验证集
   - Adam 优化器, MSE 损失
   - 早停 (验证集 loss 不再下降)

3. 优化
   - CMA-ES/GA 在 NN 上搜索
   - 或用梯度信息 (如果 NN 可微) 直接梯度下降

4. 验证
   - Top-K 候选解用 HFSS 验证
```

### 文献结果

| 阵列规模 | 方法 | PSLL | 训练数据 | 推理速度 |
|----------|------|------|----------|----------|
| 20 元 | MLP + GA | -16.5 dB | 2000 AF | ~ms/次 |
| 50 元 | CNN + PSO | -19.2 dB | 5000 AF | ~ms/次 |
| 100 元 | ResNet + CMA | -21.0 dB | 10000 AF | ~ms/次 |

## 优缺点

**优点**:
- 推理速度极快 (~μs)
- 可处理任意维度
- 可学习复杂非线性映射
- 方向图全角度预测 (不只标量)

**缺点**:
- 需要大量训练数据 (1000+)
- 无法给出不确定性估计
- 训练时间较长 (分钟级)
- 过拟合风险

```python
# 需要新增:

# 示例 (PyTorch):
import torch.nn as nn

class AntennaSurrogate(nn.Module):
    def __init__(self, n_vars, n_theta=18001):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_vars, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, n_theta)
        )
    def forward(self, x):
        return self.net(x)
```

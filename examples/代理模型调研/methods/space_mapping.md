# 空间映射 (Space Mapping) 及其局限

## 原理

空间映射 (Bandler 1994) 通过建立粗模型和细模型之间的映射关系，用少量细模型评估达到优化目的：

```
粗模型: x_c → f_c(x_c)  (快速, 如方向图乘积)
细模型: x_f → f_f(x_f)  (精确, 如 HFSS)
映射:   x_f = P(x_c)     (待学习)
```

### SM 家族

| 方法 | 映射位置 | 更新方式 | 收敛性 |
|------|----------|----------|--------|
| **ASM** (Aggressive) | 输入空间 | Broyden 拟牛顿 | 不稳定 |
| **OSM** (Output) | 输出空间 | 加性修正 | 较稳定 |
| **Manifold** | 输入+输出 | 联合更新 | 最稳定但复杂 |
| **Hybrid** | 混合 | 自适应选择 | 取决于实现 |

## ASM 在方向图对齐中的失败分析

### 实验现象

```
ASM 迭代:
  iter 0: PSLL = -14.05 dB, res_norm = 0.898
  iter 1: PSLL = -14.18 dB, res_norm = 0.512
  iter 2: PSLL = -14.90 dB, res_norm = 0.223
  iter 3: PSLL = -14.75 dB, res_norm = 0.994  ← 残差反弹
  iter 4: PSLL = -14.69 dB, res_norm = 0.728
  ...
  iter 8: PSLL = -14.81 dB, res_norm = 0.243  ← 停滞
```

### 失败根因

1. **映射非线性**: 互耦效应使位置→方向图的映射高度非线性。Broyden 假设 `f(x+h) ≈ f(x) + J·h`，但实际映射远非线性。

2. **响应空间维度不匹配**: S11 是标量函数 (频率的函数, ~100 维)，方向图是角度函数 (18001 维)。高维响应空间使 PE 更难收敛。

3. **PE 局部最优**: 参数提取是求解 `argmin ||f_f(x_f) - f_c(x_c)||`，对于非凸目标容易陷入局部最优。

4. **Jacobian 退化**: Broyden 更新 `B_{k+1} = B_k + (y - B_k·s)s^T / (s^T·s)` 在残差震荡时 Jacobian 矩阵退化，步长失控。

### 标准 SM vs 方向图 SM 对比

| | 标准 SM (S11) | 方向图 SM |
|---|---|---|
| 对齐目标 | S11(f), 标量 | pattern(θ), 向量 |
| 映射光滑度 | 较光滑 | 不光滑 |
| Jacobian 维度 | ~100 | ~18001 |
| 收敛性 | 通常收敛 | 经常不收敛 |
| 文献支持 | 大量 | 极少 |

## 为什么方向图 SM 本质上不适合

1. **互耦的位置依赖性**: 每个阵元的互耦环境随位置变化，导致映射的 Jacobian 在不同位置差异很大。

2. **方向图的全局性**: 方向图是所有阵元的叠加，单个位置的变化影响整个方向图 (非局部)。这使得映射的 Jacobian 稠密且非光滑。

3. **副瓣的敏感性**: 副瓣电平对位置微小变化极其敏感 (可能变化几个 dB)，而主瓣相对稳定。这种多尺度特性使线性近似失效。

## 替代方向

放弃显式映射，改用数据驱动的代理模型:
- 不需要假设映射形式
- 直接学习 x → PSLL 的黑箱关系
- 通过增量采样逐步提高精度

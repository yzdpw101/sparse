# 网络结构与参数

## 层与维度

每一层做: `输出 = W × 输入 + b`

| 概念 | 形状 | 说明 |
|------|------|------|
| 输入 | (n,) | n 个特征 |
| W | (m, n) | m 行 n 列 |
| b | (m,) | m 个偏置 |
| 输出 | (m,) | m 个神经元的输出 |

### 例子: 15 → 128 → 128 → 1

```python
# 第1层: 15 → 128
W1: (128, 15)    # 128×15 = 1920 个参数
b1: (128,)       # 128 个参数

# 第2层: 128 → 128
W2: (128, 128)   # 128×128 = 16384 个参数
b2: (128,)       # 128 个参数

# 第3层: 128 → 1
W3: (1, 128)     # 1×128 = 128 个参数
b3: (1,)         # 1 个参数

总参数: 2048 + 16512 + 129 ≈ 1.9 万
```

## 层数和宽度怎么定

**没有理论公式，靠经验试。**

| 问题规模 | 推荐层数 | 每层神经元 |
|---------|---------|-----------|
| 简单 (<10 维输入) | 2-3 层 | 32-64 |
| 中等 (10-50 维) | 3-4 层 | 64-256 |
| 复杂 (>50 维) | 4-6 层 | 128-512 |

## 判断标准

| 现象 | 含义 | 怎么办 |
|------|------|--------|
| 训练集误差大 | 欠拟合，网络太小 | 加宽/加深 |
| 训练集误差小，测试集误差大 | 过拟合，网络太大 | 缩小/加正则化 |
| 两者都小 | 刚好 | 可以了 |

## 针对稀布阵列 (15 维输入)

```python
import torch.nn as nn

net = nn.Sequential(
    nn.Linear(15, 128),   # 第1层: 15 → 128
    nn.ReLU(),
    nn.Linear(128, 128),  # 第2层: 128 → 128
    nn.ReLU(),
    nn.Linear(128, 1)     # 第3层: 128 → 1 (PSLL)
)
```

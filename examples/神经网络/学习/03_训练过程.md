# 训练过程

## 核心思路

训练 = 找一组 W 和 b，让所有训练样本的预测误差之和最小。

```python
loss = Σ (预测值 - 真实值)²
目标: 找 W, b 使得 loss 最小
```

## 训练循环

```python
for epoch in range(1000):
    # 1. 前向传播: 算预测值
    y_pred = net(X_train)

    # 2. 算损失
    loss = (y_pred - Y_train).pow(2).mean()

    # 3. 反向传播: 算梯度 (W 变一点, loss 变多少)
    loss.backward()

    # 4. 更新 W 和 b (往减小 loss 的方向走)
    optimizer.step()

    # 5. 清零梯度
    optimizer.zero_grad()
```

## 梯度下降直觉

```
loss
  |  *
  |   *        ← 现在在这里
  |    *
  |     *  *   *     ← 最优解在这里
  |_______________
       W 的值

梯度告诉你: W 往左走 loss 减小
所以更新: W = W - lr × 梉度
```

## 关键超参数

| 参数 | 含义 | 常用值 |
|------|------|--------|
| learning_rate (lr) | 每步走多大 | 0.001 |
| epochs | 训练多少轮 | 1000-5000 |
| batch_size | 每次用多少样本算梯度 | 32-256 |

## 欠拟合 vs 过拟合

```
训练误差小 + 测试误差大 → 过拟合 (记住了噪声)
训练误差大 + 测试误差大 → 欠拟合 (没学会规律)
训练误差小 + 测试误差小 → 刚好
```

## 对比 CMA-ES

```
CMA-ES:  随机搜索 → 不需要导数 → 几十万次 AF
梯度下降: 算梯度 → 知道方向 → 几千次 AF
```

前提: 目标函数可微分 (AF 公式可以)。

# 什么是神经网络

## 一句话定义

神经网络就是一个**可学习的数学公式**——给它输入，它输出结果，训练过程就是让这个公式越来越准。

## 最简单的结构

```
输入 x (比如 3 个数)
  ↓
[权重矩阵 W1] → [加偏置 b1] → [激活函数]    ← 第 1 层
  ↓
[权重矩阵 W2] → [加偏置 b2] → [激活函数]    ← 第 2 层
  ↓
输出 y (比如 1 个数)
```

用代码表示：

```python
y = W2 @ relu(W1 @ x + b1) + b2
```

## 神经元是什么

一个神经元做的事：

```
输入: x1, x2, x3 (多个)
计算: z = w1*x1 + w2*x2 + w3*x3 + b  (加权求和)
输出: a = relu(z)                     (激活函数)
```

多个神经元并排就是一层。

## 和查表的区别

```
查表:  记住 (0.1,0.2,0.3) → -15.2 dB
       给 (0.11,0.21,0.31) → 不知道，得再查

神经网络: 学会了 "位置稀疏 → 副瓣低" 的规律
         给任意位置都能猜个大概
```

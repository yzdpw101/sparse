# 物理信息神经网络 (PINN)

## 传统 PINN

把物理方程（偏微分方程）嵌入神经网络的损失函数，让网络输出满足物理规律。

```python
loss = (预测值 - 真实值)² + λ × (物理方程残差)²
```

适用场景: PDE 没有解析解，数值方法又太贵（流体力学、热传导等）。

## 论文中的 PCNN (南理工)

不是传统 PINN，而是**把 AF 计算公式嵌入神经网络作为可微分层**：

```
输入: 目标方向图 + 波束指标 (θ_main, PSLL_target)
  ↓
CNN 编码器 → MLP 解码器 → 输出: 幅度 A_n + 相位 φ_n
  ↓
物理层 (AF 公式, 可微分) → 预测方向图
  ↓
损失 = 主瓣约束 + 副瓣约束 → 反向传播更新权重
```

### 关键特点

1. **不需要训练数据** — 每个波束任务单独做在线优化
2. **物理层可微分** — AF 公式写在计算图里，梯度直接回传
3. **端到端优化** — 从目标方向图到激励参数，一个网络搞定

### 论文结果

| 方法 | 阵元数 | PSLL | 耗时 |
|------|--------|------|------|
| PCNN | 32 | -35.08 dB | 4.85s |
| CMA-ES | 32 | -21.65 dB | 875s |

PCNN 快 180 倍，PSLL 还低 13 dB。

### 原理

本质是用**梯度下降替代随机搜索**：

```
CMA-ES:  盲目试探 → 算 AF → 反馈 → 重复（不需要导数）
PCNN:    算梯度 → 知道往哪走 → 一步到位（需要导数）
```

AF 公式可微分 → 梯度能算 → 梯度下降能用。

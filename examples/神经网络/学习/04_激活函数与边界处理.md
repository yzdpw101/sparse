# 激活函数与边界处理

## 激活函数

没有激活函数，多层网络等价于一层线性变换。激活函数引入非线性。

| 函数 | 公式 | 输出范围 | 用途 |
|------|------|---------|------|
| ReLU | max(0, x) | [0, +∞) | 隐藏层默认选择 |
| Sigmoid | 1/(1+e^{-x}) | (0, 1) | 输出需要在 (0,1) 时 |
| Tanh | (e^x - e^{-x})/(e^x + e^{-x}) | (-1, 1) | 输出需要在 (-1,1) 时 |

## 边界处理

优化变量有边界约束时，用激活函数天然映射。

### 幅度: [0, 1]

```python
# 原始输出任意实数 → sigmoid → (0, 1)
A = torch.sigmoid(raw_output)
```

### 相位: [-π, π]

```python
# 原始输出任意实数 → tanh × π → (-π, π)
phi = torch.tanh(raw_output) * np.pi
```

### 梯度回传

```
原始值 (-∞, +∞) → sigmoid → 输出 (0, 1)
       ↑                        ↓
  梯度更新这里            loss 算在这里

sigmoid 的导数: d(sigmoid)/dx = sigmoid(x) × (1 - sigmoid(x))
```

不需要手动处理边界，激活函数自动保证。

## 针对稀布阵列的边界

```
优化变量 x ∈ [0,1]
  ↓ sigmoid (确保在 [0,1])
  ↓ stick-breaking 映射 (确保 dmin 约束)
  ↓ cumsum (确保有序)
  ↓ 缩放 (确保孔径约束)
  ↓ AF 计算
  → PSLL
```

整条链路可微分，梯度可以一路回传。

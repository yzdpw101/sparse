## 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| 神经网络 | 一堆矩阵乘法，用来拟合任意函数 |
| 训练 | 找一组 W 和 b，让所有训练样本的预测误差最小 |
| 欠拟合 | 网络太小，学不到规律 |
| 过拟合 | 网络太大，把噪声也记住了 |
| 梯度下降 | 沿着 loss 减小的方向更新 W 和 b |
| 可微分 | 能算梯度，梯度下降才能用 |
| PINN | 把物理方程嵌入神经网络，让网络遵守物理规律 |

# 与稀布阵列优化的结合

## 两种思路

### 思路 A: 神经网络作为代理模型 (学习笔记)

训练神经网络学习 `位置 → PSLL` 的映射，替代 AF 计算。

```
训练: 大量采样 → AF 算 PSLL → 训练 NN → 保存模型
使用: 输入位置 → NN 预测 PSLL (不用算 AF)
```

- 适用于: 固定配置 (频率、角度、阵元数) 的批量优化
- 局限: 换配置要重训

### 思路 B: 端到端可微分优化 (论文思路)

把 stick-breaking + AF 公式嵌入神经网络，直接用梯度下降优化位置。

```
输入: 随机初始化
  ↓
网络 → 优化变量 → stick-breaking → 位置 → AF → 方向图
  ↓
损失 = 副瓣约束 → 梯度回传 → 更新网络权重
  ↓
输出: 最优位置
```

- 优点: 不需要训练数据，每个任务独立优化
- 挑战: stick-breaking 的梯度稳定性

## 稀布阵列的特殊挑战

| 挑战 | 原因 | 解决方案 |
|------|------|---------|
| 间距约束 | dmin 限制 | stick-breaking 映射 |
| 边界约束 | 位置在 [0, L] | sigmoid 映射 |
| 非凸性 | 多个局部最优 | 多次随机初始化 |
| 副瓣敏感 | 位置微小变化 → PSLL 跳变 | 梯度裁剪 |

## 可微分链路

```
x_raw (任意实数)
  ↓ sigmoid           → x ∈ [0,1]         (可微)
  ↓ stick-breaking    → gaps (>= dmin)    (可微: clamp + cumsum)
  ↓ 缩放             → 物理位置 ∈ [0,L]  (可微)
  ↓ AF 公式           → 复数方向图        (可微)
  ↓ 取模 + 归一化     → dB 方向图         (可微)
  ↓ 找副瓣           → PSLL              (不可微: argmax)
```

最后一步"找副瓣"不可微，需要用软近似 (如 log-sum-exp) 代替 argmax。

# 优化器对比报告

## 测试配置

- 阵列: 对称固定孔径线阵, dmin=0.5λ, 无间距上限
- Theta: [-90°, 90°], theta0=0°, step=0.1°
- MC=5, max_iter=500, N_JOBS=8

## 被测算法

| 算法 | 来源 | 特点 |
|---|---|---|
| **CMA-ES (C++ 风格)** | 自实现 `_run_cma_cpp` | 无 sigmoid, clamp [0,1], 随机初始, 2x 种群 |
| **CMA-ES (混沌)** | `_run_cma_cpp(chaotic_init=True)` | Tent 混沌映射生成初始 xmean |
| **DMDE** | 王莉 2025 论文复刻 | DE/best/1 + 自适应 F + Cauchy-Gaussian 双变异 |
| **GWO** | Mirjalili 2014 | Grey Wolf Optimizer, α/β/δ 位置更新 |

## 结果 (stick-breaking 映射)

| 配置 | CMA-ES | CMA-混沌 | DMDE | GWO |
|---|---|---|---|---|
| 78元/73λ (38维) | -21.98 | **-22.34** | -21.17 | -18.11 |
| 132元/90.5λ (65维) | **-25.02** | -25.00 | -23.64 | -20.90 |
| 152元/98.5λ (75维) | -24.12 | **-24.27** | -23.63 | -21.66 |

## 分析

### CMA-ES 为何最优

Stick-breaking 映射产生强层级依赖——v[0] 控制最外侧间隙，v[-1] 控制最内侧，变量影响力递减。CMA-ES 的**协方差矩阵**能自动学习这种依赖关系，调整搜索方向。

而 GWO 使用 α/β/δ 三个最优个体的线性插值，DMDE 使用 DE/best/1 差分变异——两者都假设变量间**独立**，无法捕捉层级依赖。

### 混沌初始化

Tent 混沌映射在 78 元 (+0.36 dB) 和 152 元 (+0.15 dB) 上有小幅改进，132 元几乎持平 (-0.02 dB)。效果不够稳定，但实现成本几乎为零，建议作为可选开关保留。

### GWO 为何失败

GWO 在 stick-breaking 下比 CMA-ES 差 3-5 dB。位置更新公式 $X = (X_\alpha + X_\beta + X_\delta)/3$ 对所有维度施加相同的扰动模式，完全无法适应 stick-breaking 中各维度不同的有效尺度。

### DMDE 的论文差异

论文 DMDE 在相同配置下报告 -25.49 dB (132元)，我们的 DMDE 仅 -23.64 dB。差 1.85 dB 的原因:
1. 论文使用**直接位置编码**（每变量独立控制一个阵元位置）
2. 论文可能使用 **θ 步长 0.1°** 但峰值搜索范围受限（我们早期的 C++ 代码验证过这个 bug）
3. 论文使用更大的评估预算（MC=50）

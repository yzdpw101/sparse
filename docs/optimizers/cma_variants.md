## 变体

| 变体 | 初始 xmean | 种群 | sigmoid | 约束处理 |
|---|---|---|---|---|
| pycma CMA-ES | x0=0 | 4+3ln(D) | σ: ℝ→(0,1) | 无界 |
| C++ 风格 CMA-ES | rand [0,1] | 2×(4+3ln(D)) | 无 | clamp [0,1] |
| C++ + 混沌 | Tent map | 2×(4+3ln(D)) | 无 | clamp [0,1] |

## 关键差异分析

### 1. 种群大小
C++ 风格默认 `λ = 2×(4+3ln(D))`, pycma 默认 `λ = 4+3ln(D)`。2x 种群提供更好的多样性，对多模态问题有帮助。计算成本也 2x。

### 2. Sigmoid vs Clamp
pycma 用 sigmoid: ℝ → (0,1)。优点: 平滑可微，全局探索。缺点: 永远达不到真正的 0 或 1（需要 x→±∞），极端分配的梯度被压缩。

C++ 风格用 clamp: [0,1]。优点: 线性映射，v=0/1 可达。缺点: 需要约束 CMA-ES（边界处理）。

对于 stick-breaking 的极端分配需求（v=1 吃掉全部剩余长度），clamp 更合适。

### 3. Tent 混沌初始化
- 78元: +0.36 dB，改进明显
- 132元: -0.02 dB，无影响
- 152元: +0.15 dB，小幅改进

混沌初始化增加初始解的多样性，对于低维问题 (78元, 38维) 有帮助，高维问题收益递减。

### 4. 随机初始 vs x0=0
pycma 固定从 x0=0（sigmoid 中心=0.5）开始，C++ 风格随机初始化。
随机初始增加首代多样性，适合不提供初始解的场景。

## 建议

- 默认使用 C++ 风格 CMA-ES (clamp [0,1], 2x 种群, 随机初始)
- 低维 (<50) 可开启 `chaotic_init=True`
- 有好的初始解时，传入 `x0` 参数
- 需要 backward-compatible 时使用 pycma (method="cma")
